Небольшие игры и симуляции с использованием модуля Pygame.  
Каждый проект самодостаточен и может запускаться отдельно.

[**fifteen**](https://github.com/englishtech/pygame/tree/main/fifteen) - классическая головоломка "Пятнашки" с подсчётом ходов

[**knb**](https://github.com/englishtech/pygame/tree/main/knb) - динамическая симуляция "Камень-Ножницы-Бумага" со 150 спрайтами

[**smiley**](https://github.com/englishtech/pygame/tree/main/smiley) - игра-платформер со смайликом, лайками и препятствиями

[tictactoe](https://github.com/englishtech/pygame/tree/main/tictacoe) - крестики-нолики
